## 1. プロジェクト概要

ここちさん（Vライバー @Ov_037）の「緑のきつね」キャラクターを、  
単なる見た目の羅列ではなく、**長期的に使える生きた設定資産**として整理・拡張した成果物です。

提供された6枚のビジュアルを基に、コアデザインの固定・ロアの深掘り・ベースビジュアル・表情バリエーションまでを一貫して構築しました。

### 最終的に目指すもの
- Character Bible（設定資料）
- 一貫性を保ったビジュアル資産群
- 運用ガイドライン

## 2. コア固定要素（絶対不変）

| 要素 | 詳細 |
|------|------|
| 髪 | ミントグリーン〜銀白のロングヘア。光を受けると半透明のオーロラ光。腰下〜床まで |
| 耳 | 大きな狐耳。外側ミント、内側白。先端がわずかに透ける |
| 尻尾 | 9本以上のふわふわ多重尾。根本白、先端ミント〜紫グラデ。光を帯び、空気に溶けるように動く |
| 目 | 澄んだエメラルドグリーン。赤みを帯びた虹彩の縁 |
| 額 | 赤い「第三の目」または魔紋。開閉可能 |
| 花 | 白〜薄紫の椿（山茶花）を耳元に一輪。常に新鮮 |
| 肌・雰囲気 | 透けるように白い。常に微かな光粒子・泡・葉が舞う |
| 色テーマ | メイン：エメラルドグリーン / サブ：銀白・薄紫・金 |

## 3. 拡張設定（ロア）

**名前・称号**  
ここち（正式：ここ(ち)）  
通称「緑のきつね」「ミントの九尾」「ここん」  
称号：超時空ラジかる・プラネットの守護狐 / ポ時間の主

**起源**  
「ここ」という「今この瞬間」を守護する存在として生まれた。  
人間の「心地よい時間（ポ時間）」を集めて生きる。  
尻尾が9本以上あるのは「過去の心地よい記憶」をそれぞれ1本に宿しているから。  
第三の目が開くと、相手の「本当に心地よいもの」が見える。

**人格**  
- 表層：優しくて少し天然、配信では「(´>ω∂`)」顔文字を多用する癒し系  
- 中層：実はかなり観察眼が鋭く、視聴者の「今」を大切にしようとする  
- 深層：自分が「心地よさ」を与える側であり続けるために、時折孤独を感じる。だからこそ多様な「姿」を持つ

## 4. 衣装バリエーション（モード）

1. **霊狐の衣** — 藤の花と満月の下で、半透明の巫女装束。純粋な癒しモード  
2. **サイバー狐** — ネオン街の夜。テックジャケット。現代の迷子たちを導くモード  
3. **ゴシック狐** — 黒レースの日傘と深緑のドレス。少し影のある大人の癒し  
4. **機装狐** — 白緑のメカスーツ。未来を守るモード  
5. **神代の狐** — 金刺繍の神衣＋緑の結晶杖。根源の守護モード  
6. **ステージ狐** — フリルたっぷりのアイドル衣装。みんなの光になるモード  

（すべてコア固定要素を保持）
